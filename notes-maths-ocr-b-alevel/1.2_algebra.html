2. Surds

A surd is an irrational root left in exact form. Working in surds keeps answers exact; decimals introduce rounding error.

The rules

$$\sqrt{ab} = \sqrt{a}\,\sqrt{b}, \qquad \sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}, \qquad \left(\sqrt{a}\right)^2 = a$$

Simplify by extracting the largest square factor:

$$\sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}, \qquad \sqrt{8} + \sqrt{2} = 2\sqrt{2} + \sqrt{2} = 3\sqrt{2}$$
\(\sqrt{a+b} \neq \sqrt{a} + \sqrt{b}\). Test it: \(\sqrt{9+16} = 5\), but \(\sqrt 9 + \sqrt{16} = 7\). The product rule holds; the sum rule does not.

Rationalising the denominator

For a single surd, multiply top and bottom by that surd:

$$\frac{1}{\sqrt 5} = \frac{1}{\sqrt 5}\times\frac{\sqrt 5}{\sqrt 5} = \frac{\sqrt 5}{5}$$

For a denominator \(a + \sqrt b\), multiply by its conjugate \(a - \sqrt b\), using the difference of two squares to clear the surd:

Worked example. Rationalise \(\dfrac{1}{3+\sqrt 5}\). $$\frac{1}{3+\sqrt5}\times\frac{3-\sqrt5}{3-\sqrt5} = \frac{3-\sqrt5}{9-5} = \frac{3-\sqrt5}{4}$$
Worked example. Rationalise \(\dfrac{\sqrt7-\sqrt3}{\sqrt7+\sqrt3}\). $$\frac{(\sqrt7-\sqrt3)^2}{(\sqrt7+\sqrt3)(\sqrt7-\sqrt3)} = \frac{7-2\sqrt{21}+3}{7-3} = \frac{10-2\sqrt{21}}{4} = \frac{5-\sqrt{21}}{2}$$

4. Quadratic equations

Three routes, plus the graphical picture (spec refs a2, a6).

Factorising

$$x^2 - 5x + 6 = 0 \;\Longrightarrow\; (x-2)(x-3)=0 \;\Longrightarrow\; x=2 \text{ or } x=3$$

Completing the square

$$x^2 + 6x + 2 = (x+3)^2 - 9 + 2 = (x+3)^2 - 7$$

This form reads off the vertex directly: the minimum of \(y=(x+3)^2-7\) is at \((-3,-7)\).

The formula

$$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$$

Quadratics in disguise

Worked example. Solve \(2^{2x} - 5\cdot 2^x + 4 = 0\).

Let \(u = 2^x\). Since \(2^{2x} = (2^x)^2 = u^2\):

$$u^2 - 5u + 4 = 0 \Longrightarrow (u-1)(u-4)=0 \Longrightarrow u=1 \text{ or } u=4$$

So \(2^x = 1\) gives \(x=0\), and \(2^x = 4\) gives \(x=2\).

Worked example. Solve \(x^4 - 5x^2 + 4 = 0\).

Let \(u=x^2\): \(u^2-5u+4=0\), so \(u=1\) or \(u=4\), giving \(x = \pm 1\) or \(x = \pm 2\) — four roots.

5. The discriminant

For \(ax^2+bx+c=0\), the discriminant is \(\Delta = b^2 - 4ac\) (spec ref a3).
DiscriminantRootsGraph and the \(x\)-axis
\(b^2-4ac > 0\)Two distinct real rootsCrosses twice
\(b^2-4ac = 0\)One repeated rootTouches (tangent)
\(b^2-4ac < 0\)No real rootsNever meets it
Worked example. Find the values of \(k\) for which \(kx^2+4x+k=0\) has a repeated root. $$b^2-4ac = 16 - 4k^2 = 0 \Longrightarrow k^2 = 4 \Longrightarrow k = \pm 2$$
Worked example. Find the values of \(k\) for which \(kx^2+(k+3)x+4=0\) has no real roots. $$(k+3)^2 - 16k < 0$$ $$k^2 + 6k + 9 - 16k < 0 \Longrightarrow k^2 - 10k + 9 < 0 \Longrightarrow (k-1)(k-9) < 0$$

A negative product means \(k\) lies between the roots: \(1 < k < 9\).

"Two distinct roots" means \(>0\); "two real roots" or "real roots" usually allows the repeated case, so \(\ge 0\). Read the wording — this distinction decides whether your final answer uses \(<\) or \(\le\).

Tangency

A line meets a curve where their equations are equal. Substituting and demanding \(\Delta=0\) is the standard condition for the line to be a tangent.

Worked example. Find the condition for \(y=mx+c\) to be tangent to \(y=x^2\). $$x^2 = mx + c \Longrightarrow x^2 - mx - c = 0$$

Tangency requires \(\Delta = 0\): \((-m)^2 - 4(1)(-c) = m^2 + 4c = 0\).

6. Simultaneous equations

Two linear equations: eliminate or substitute (a4). One linear and one quadratic: always substitute the linear into the quadratic (a5).

Worked example. Solve \(y = x+1\) and \(x^2+y^2=25\). $$x^2 + (x+1)^2 = 25 \Longrightarrow 2x^2 + 2x + 1 = 25 \Longrightarrow x^2 + x - 12 = 0$$ $$(x+4)(x-3)=0 \Longrightarrow x = -4 \text{ or } x = 3$$

Substituting back into \(y=x+1\): the solutions are \((-4,-3)\) and \((3,4)\).

Substitute back into the linear equation, not the quadratic — it is quicker and cannot introduce spurious roots. And always pair the values: writing "\(x=3\) or \(x=-4\), \(y=4\) or \(y=-3\)" without pairing loses marks.

Geometrically the solutions are the points of intersection of the two graphs (a6). If the resulting quadratic has no real roots, the graphs do not meet.

7. Inequalities

Linear

Solve as an equation, but reverse the inequality sign when multiplying or dividing by a negative.

Quadratic

Factorise, find the critical values, then read the sign from a sketch (a8).

Worked example. Solve \(x^2 - 4x - 5 > 0\). $$(x-5)(x+1) > 0$$

Critical values \(x=-1\) and \(x=5\). The parabola opens upwards, so it is above the axis outside the roots:

$$x < -1 \quad\text{or}\quad x > 5$$
A quick sketch settles the direction every time. For an upward parabola: \(<0\) between the roots, \(>0\) outside them. Guessing gets it backwards half the time.

Inequalities with an algebraic fraction

Do not multiply both sides by \(x-3\): its sign is unknown, so the inequality may or may not reverse. Instead collect on one side over a common denominator, or multiply by the square \((x-3)^2\), which is always positive.

Set notation

Solutions may be expressed with "and"/"or" or in set notation (a9):

  • \(x \le 1\) or \(x \ge 4\)   →   \(\{x : x \le 1\} \cup \{x : x \ge 4\}\)
  • \(2 < x < 5\)   →   \(\{x : x > 2\} \cap \{x : x < 5\}\)
Two separate intervals need or (union). Writing "\(x < -1\) and \(x > 5\)" describes numbers that are simultaneously less than \(-1\) and greater than 5 — nothing at all.

Worked example. \(y\) is inversely proportional to \(x^2\), and \(y=4\) when \(x=3\). Find \(y\) when \(x=6\). $$y = \frac{k}{x^2} \Longrightarrow 4 = \frac{k}{9} \Longrightarrow k = 36$$ $$x=6:\quad y = \frac{36}{36} = 1$$

9. Partial fractions

Partial fractions split a single algebraic fraction into a sum of simpler ones (spec ref a15). MEI restricts this to denominators with up to three linear factors, and includes repeated (squared) linear factors.
DenominatorForm to assume
\((x+a)(x+b)\)\(\dfrac{A}{x+a} + \dfrac{B}{x+b}\)
\((x+a)(x+b)(x+c)\)\(\dfrac{A}{x+a} + \dfrac{B}{x+b} + \dfrac{C}{x+c}\)
\((x+a)^2(x+b)\)\(\dfrac{A}{x+a} + \dfrac{B}{(x+a)^2} + \dfrac{C}{x+b}\)
Worked example. Express \(\dfrac{5x+1}{(x+1)(x-2)}\) in partial fractions. $$\frac{5x+1}{(x+1)(x-2)} = \frac{A}{x+1} + \frac{B}{x-2}$$

Multiply through by \((x+1)(x-2)\):

$$5x+1 = A(x-2) + B(x+1)$$

Substitute strategic values. Let \(x=2\): \(11 = 3B\), so \(B = \tfrac{11}{3}\). Let \(x=-1\): \(-4 = -3A\), so \(A = \tfrac{4}{3}\).

$$\frac{5x+1}{(x+1)(x-2)} = \frac{4}{3(x+1)} + \frac{11}{3(x-2)}$$
For a repeated factor \((x+a)^2\) you need both \(\dfrac{A}{x+a}\) and \(\dfrac{B}{(x+a)^2}\). Omitting the first term is the single most common error here — the system then has no solution and the algebra collapses.
Substituting the values that make each factor zero is fastest. If a term remains (as with a repeated factor), compare coefficients of the highest power, or substitute one more convenient value such as \(x=0\).

10. Common pitfalls

  • Writing \(\sqrt{a+b} = \sqrt a + \sqrt b\).
  • Forgetting the negative root: \(x^2=16\) gives \(x = \pm 4\), not just 4.
  • Multiplying an inequality by a negative — or by an expression of unknown sign — without reversing or justifying.
  • Joining two separate solution intervals with "and" instead of "or".
  • Reading a quadratic inequality off the wrong side of the parabola.
  • Omitting the \(\dfrac{A}{x+a}\) term for a repeated linear factor in partial fractions.
  • Confusing "two distinct real roots" (\(\Delta > 0\)) with "real roots" (\(\Delta \ge 0\)).
  • Losing the pairing of \(x\) and \(y\) values in simultaneous equations.
