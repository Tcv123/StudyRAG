1.7 Trigonometry

2. Radians, arcs and sectors

One radian is the angle subtended at the centre by an arc equal in length to the radius. \(\pi\) radians \(= 180^\circ\).

For a sector of radius \(r\) subtending angle \(\theta\) in radians:

$$\text{arc length } s = r\theta, \qquad \text{sector area } A = \tfrac12 r^2\theta$$
Worked example. Find the arc length and sector area for \(r=6\), \(\theta = \tfrac{\pi}{3}\). $$s = 6 \times \tfrac{\pi}{3} = 2\pi, \qquad A = \tfrac12 (36)\left(\tfrac{\pi}{3}\right) = 6\pi$$
These two formulae require radians. Substituting degrees gives an answer wrong by a factor of about 57. If a question is set in radians, keep your calculator in radian mode throughout.

3. Sine and cosine rules; area

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}, \qquad a^2 = b^2+c^2-2bc\cos A, \qquad \text{Area} = \tfrac12 ab\sin C$$

Use the cosine rule when you have three sides, or two sides and the angle between them. Use the sine rule otherwise.

The sine rule has an ambiguous case: given two sides and a non-included angle, \(\sin\theta = k\) has two solutions in \(0^\circ\) to \(180^\circ\), namely \(\theta\) and \(180^\circ - \theta\). Check whether both give a valid triangle.

5. Solving trigonometric equations

The calculator gives one value — the principal value. Every other solution in the range must be found from the symmetry of the graph.

EquationSecond solution in \([0, 2\pi)\)
\(\sin x = k\)\(\pi - x\)
\(\cos x = k\)\(2\pi - x\)
\(\tan x = k\)\(x + \pi\)
Worked example. Solve \(\sin x = \tfrac{\sqrt3}{2}\) for \(0 \le x < 2\pi\).

Principal value \(x = \tfrac{\pi}{3}\). Second solution \(\pi - \tfrac{\pi}{3} = \tfrac{2\pi}{3}\). So \(x = \tfrac{\pi}{3}\) or \(\tfrac{2\pi}{3}\).

Worked example. Solve \(\cos x = -\tfrac12\) for \(0 \le x < 2\pi\).

\(x = \tfrac{2\pi}{3}\) or \(\tfrac{4\pi}{3}\).

Equations in a multiple angle

For \(\sin 2x = k\) over \(0^\circ \le x < 360^\circ\), widen the range first: \(2x\) runs over \(0^\circ\) to \(720^\circ\). Solve for \(2x\) across that doubled range, then halve every answer. Halving first loses half the solutions.
Worked example. Solve \(\sin 2x = 0.5\) for \(0^\circ \le x < 360^\circ\).

Let \(u = 2x\), so \(0^\circ \le u < 720^\circ\). Then

$$u = 30^\circ,\ 150^\circ,\ 390^\circ,\ 510^\circ$$

Halving: \(x = 15^\circ,\ 75^\circ,\ 195^\circ,\ 255^\circ\) — four solutions.

6. Reciprocal functions and Pythagorean identities

$$\sec\theta = \frac{1}{\cos\theta}, \qquad \operatorname{cosec}\theta = \frac{1}{\sin\theta}, \qquad \cot\theta = \frac{1}{\tan\theta} = \frac{\cos\theta}{\sin\theta}$$

From \(\sin^2\theta + \cos^2\theta = 1\), dividing by \(\cos^2\theta\) and then by \(\sin^2\theta\) gives:

$$1 + \tan^2\theta = \sec^2\theta, \qquad 1 + \cot^2\theta = \operatorname{cosec}^2\theta$$
\(\sec\) goes with \(\cos\) and \(\operatorname{cosec}\) with \(\sin\) — note the mismatch of first letters, which is exactly why it is misremembered. Look at the third letter: sec → cos.

7. Compound and double angle formulae

$$\sin(A \pm B) = \sin A\cos B \pm \cos A \sin B$$ $$\cos(A \pm B) = \cos A\cos B \mp \sin A \sin B$$ $$\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A \tan B}$$
Note the sign flip in the cosine formula: \(\cos(A+B)\) uses a minus. This is the most commonly misquoted identity in the topic.

Setting \(B=A\) gives the double angle formulae:

$$\sin 2\theta = 2\sin\theta\cos\theta$$ $$\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$$ $$\tan 2\theta = \frac{2\tan\theta}{1-\tan^2\theta}$$
The three forms of \(\cos 2\theta\) are not interchangeable in practice — choose the one that matches the rest of the equation. If the equation also contains \(\sin\theta\), use \(1-2\sin^2\theta\) so everything is in one function.
Worked example. Solve \(3\cos 2x + \sin x = 2\) for \(0 \le x < 2\pi\).

Choose \(\cos 2x = 1-2\sin^2 x\) to match the \(\sin x\):

$$3(1-2\sin^2 x) + \sin x = 2 \Longrightarrow 6\sin^2 x - \sin x - 1 = 0$$ $$(3\sin x + 1)(2\sin x - 1) = 0$$

So \(\sin x = \tfrac12\), giving \(x = \tfrac{\pi}{6}, \tfrac{5\pi}{6}\); or \(\sin x = -\tfrac13\), giving \(x = 3.481, 5.943\) radians (3 d.p.).

Worked example. Simplify \(\dfrac{1-\cos 2\theta}{\sin 2\theta}\). $$\frac{1-(1-2\sin^2\theta)}{2\sin\theta\cos\theta} = \frac{2\sin^2\theta}{2\sin\theta\cos\theta} = \frac{\sin\theta}{\cos\theta} = \tan\theta$$

8. The \(R\sin(x \pm \alpha)\) form

Any expression \(a\sin x + b\cos x\) can be written as a single trigonometric function: $$a\sin x + b\cos x = R\sin(x+\alpha), \qquad R = \sqrt{a^2+b^2}, \qquad \tan\alpha = \frac{b}{a}$$

This form makes maxima, minima and solutions immediate: the expression ranges between \(-R\) and \(R\).

Worked example. Express \(3\sin x + 4\cos x\) as \(R\sin(x+\alpha)\), and state its maximum. $$R = \sqrt{3^2+4^2} = 5, \qquad \tan\alpha = \tfrac43 \Longrightarrow \alpha = 0.927 \text{ rad (3 s.f.)}$$ $$3\sin x + 4\cos x = 5\sin(x + 0.927)$$

The maximum is \(5\), attained when \(\sin(x+\alpha) = 1\).

Worked example. Find the maximum of \(5\sin x + 12\cos x\).

\(R = \sqrt{25+144} = 13\), so the maximum is 13 and the minimum is \(-13\).

9. Small angle approximations

For small \(\theta\) measured in radians:

$$\sin\theta \approx \theta, \qquad \tan\theta \approx \theta, \qquad \cos\theta \approx 1 - \frac{\theta^2}{2}$$

A consequence used repeatedly in calculus:

$$\lim_{\theta \to 0}\frac{\sin\theta}{\theta} = 1$$
These hold only in radians. They are also the reason the derivative of \(\sin x\) is \(\cos x\) only when \(x\) is in radians — which is why all calculus with trigonometric functions is done in radians.

10. Common pitfalls

  • Leaving the calculator in the wrong mode — degrees when the question is in radians, or the reverse.
  • Giving only the principal value and missing the other solutions in the range.
  • Halving before solving in a multiple-angle equation, losing half the answers.
  • Writing \(\cos(A+B) = \cos A\cos B + \sin A\sin B\) — the sign is minus.
  • Pairing \(\sec\) with \(\sin\) instead of \(\cos\).
  • Choosing a form of \(\cos 2\theta\) that leaves two different trigonometric functions in the equation.
  • Using \(s=r\theta\) or \(A=\tfrac12 r^2\theta\) with \(\theta\) in degrees.
  • Applying small angle approximations to angles in degrees.
  • Dividing an equation by \(\cos x\) and silently losing the solutions where \(\cos x = 0\).
