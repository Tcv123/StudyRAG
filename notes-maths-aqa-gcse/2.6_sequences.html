2.6.1 Generating Sequences (A23)

A sequence is an ordered list of numbers called terms. The position of a term is usually called $n$: the 1st term has $n = 1$, the 2nd term $n = 2$, and so on.

Term-to-term rules

A term-to-term rule tells you how to get from one term to the next. You need a starting term as well as the rule.

The first term of a sequence is 6. The rule is "multiply by 3 then subtract 4". Write down the next three terms.

$6 \times 3 - 4 = 14$,   $14 \times 3 - 4 = 38$,   $38 \times 3 - 4 = 110$
Sequence: 6, $\mathbf{14, 38, 110}$

Term-to-term rules can be written with suffix notation: $u_n$ is the $n$th term and $u_{n+1}$ is the term after it. So "multiply by 2 then subtract 3, starting at 5" is written $u_{n+1} = 2u_n - 3$, $u_1 = 5$, giving 5, 7, 11, 19, … Any unusual recursive rule like this will always be defined in the question.

Position-to-term rules (the $n$th term)

A position-to-term rule gives any term directly from its position. Substitute $n = 1, 2, 3, \ldots$

Write down the first three terms and the 20th term of the sequence with $n$th term $5n - 2$.

$n = 1$: $5 - 2 = 3$;   $n = 2$: $10 - 2 = 8$;   $n = 3$: $15 - 2 = 13$
$n = 20$: $5 \times 20 - 2 = \mathbf{98}$
Write down the first three terms of the sequence with $n$th term $n^2 + 4$.

$1 + 4 = 5$,   $4 + 4 = 8$,   $9 + 4 = 13$   →   $\mathbf{5, 8, 13}$

Sequences from patterns and diagrams

Each new square needs 3 more sticks, so the number of sticks goes 4, 7, 10, … with $n$th term $3n + 1$. Pattern 50 needs $3 \times 50 + 1 = 151$ sticks.

Triangular numbers

Each triangle adds a new bottom row one dot longer than the last, so the differences are 2, 3, 4, 5, … The 12th triangular number is $\dfrac{12 \times 13}{2} = 78$.

Arithmetic progressions

An arithmetic (or linear) sequence increases or decreases by the same amount each time. This amount is the common difference $d$. Example: 20, 17, 14, 11, … has $d = -3$.

Fibonacci-type sequences

In a Fibonacci-type sequence, each term is the sum of the two previous terms. The Fibonacci sequence itself is 1, 1, 2, 3, 5, 8, 13, 21, … but any two starting numbers can be used.

If the first two terms are $a$ and $b$, the sequence is $a,\ b,\ a + b,\ a + 2b,\ 2a + 3b,\ 3a + 5b, \ldots$ This lets you form equations.

A Fibonacci-type sequence has 3rd term 11 and 5th term 29. Find the first two terms.

3rd term: $a + b = 11$    5th term: $2a + 3b = 29$
Double the first: $2a + 2b = 22$. Subtract: $b = 7$, so $a = 4$.
Sequence: $\mathbf{4, 7}$, 11, 18, 29 ✓

Geometric progressions

In a geometric sequence each term is multiplied by the same number, the common ratio $r$. Find $r$ by dividing a term by the one before it. At Foundation $r$ is a positive rational number, e.g. 2, 3, $\tfrac{1}{2}$, 1.5.
Geometric sequence with first term $a$ and common ratio $r$: $$a,\ ar,\ ar^2,\ ar^3, \ldots \qquad n\text{th term} = ar^{n-1}$$
A geometric sequence has first term 5 and a positive common ratio. The 3rd term is 45. Find the 6th term.

$5r^2 = 45 \Rightarrow r^2 = 9 \Rightarrow r = 3$
Terms: 5, 15, 45, 135, 405, $\mathbf{1215}$
A geometric sequence begins 64, 16, … Find the next two terms.

$r = 16 \div 64 = \tfrac{1}{4}$, so the next terms are $16 \times \tfrac14 = \mathbf{4}$ and $\mathbf{1}$.

Quadratic sequences

A quadratic sequence has first differences that change, but second differences that are constant. Its $n$th term contains $n^2$ as the highest power.

The second difference is constant (2), so 3, 8, 15, 24, … is quadratic. Continuing the pattern of first differences (+11, +13) gives the next terms 35 and 48.

To decide what type a sequence is: constant first difference ⇒ arithmetic; constant second difference ⇒ quadratic; constant ratio ⇒ geometric; each term = sum of previous two ⇒ Fibonacci-type.

Other sequences Higher

At Higher tier, geometric sequences can have a surd common ratio or a negative ratio, and you may meet other sequences defined in the question.

A geometric sequence begins $3,\ 3\sqrt{2},\ 6, \ldots$ Find the 9th term.

$r = \dfrac{3\sqrt{2}}{3} = \sqrt{2}$
9th term $= 3 \times (\sqrt{2})^8 = 3 \times 2^4 = 3 \times 16 = \mathbf{48}$
A geometric sequence has first term 2 and second term $2\sqrt{3}$. Which is the first term greater than 500?

$r = \sqrt{3}$, and every two steps multiply by $(\sqrt{3})^2 = 3$: terms 2, $2\sqrt{3}$, 6, $6\sqrt{3}$, 18, …
11th term $= 2 \times 3^5 = 486$; 12th term $= 486\sqrt{3} \approx 841.8$. So the $\mathbf{12th}$ term.

A negative ratio makes the signs alternate: 5, $-10$, 20, $-40$, 80, … has $r = -2$.

2.6.3 The $n$th Term of a Linear Sequence (A25)

For a linear sequence with common difference $d$: $$n\text{th term} = dn + (\text{first term} - d)$$ The value "first term $- d$" is the zeroth term — the term before the first.
Find the $n$th term of 7, 11, 15, 19, …

Common difference 4, so start with $4n$: 4, 8, 12, 16, …
Each term is 3 more than $4n$, so the $n$th term is $\mathbf{4n + 3}$.
Find the $n$th term of 40, 37, 34, 31, … and the 25th term.

$d = -3$; zeroth term $= 40 + 3 = 43$. $n$th term $= \mathbf{43 - 3n}$
25th term $= 43 - 75 = \mathbf{-32}$

Is a number in the sequence?

Set the $n$th term equal to the number and solve. It is a term only if $n$ is a positive whole number.

Is 150 a term of $7n + 3$?   $7n + 3 = 150 \Rightarrow 7n = 147 \Rightarrow n = 21$. Yes, it is the 21st term.
Is 98 a term of $4n + 4$?   $4n = 94 \Rightarrow n = 23.5$. Not a whole number, so no.

Problems with linear sequences

Sequence A has $n$th term $5n - 4$. Sequence B begins 100, 96, 92, … At which position are the terms equal?

B: $d = -4$, zeroth term 104, so $n$th term $= 104 - 4n$.
$5n - 4 = 104 - 4n \Rightarrow 9n = 108 \Rightarrow n = 12$. Both 12th terms equal $\mathbf{56}$.
1 table seats 6, 2 tables seat 10, 3 tables seat 14. What is the least number of tables for 75 people?

$n$th term $4n + 2$. Need $4n + 2 \ge 75 \Rightarrow n \ge 18.25$, so $\mathbf{19}$ tables (18 tables seat only 74).
The coefficient of $n$ is the common difference, not the first term. A common error is writing 3, 7, 11, 15 as "$n + 4$". Always check your formula by substituting $n = 1$ and $n = 2$.

2.6.4 The $n$th Term of a Quadratic Sequence Higher

For a quadratic sequence with $n$th term $an^2 + bn + c$: $$a = \frac{\text{second difference}}{2}$$
  1. Find the second difference and halve it to get $a$.
  2. Subtract $an^2$ from each term.
  3. Find the $n$th term of the remaining linear sequence ($bn + c$).
  4. Combine: $an^2 + bn + c$, and check with $n = 1$.
Find the $n$th term of 3, 10, 21, 36, 55, …

First differences: 5, 3, 1, $-1$   Second difference: $-2$, so $a = -1$.
Term $- (-n^2)$, i.e. term $+ n^2$: 13, 21, 29, 37, 45 ⇒ $8n + 5$
$n$th term $= \mathbf{-n^2 + 8n + 5}$. Check: $n = 2$: $-4 + 16 + 5 = 17$ ✓
The $n$th term of a sequence is $n^2 + 2n$. Show that 120 is a term.

$n^2 + 2n = 120 \Rightarrow n^2 + 2n - 120 = 0 \Rightarrow (n + 12)(n - 10) = 0$
$n = 10$ (reject $n = -12$ as positions are positive). 120 is the $\mathbf{10th}$ term.
Halve the second difference — using the second difference itself as the coefficient of $n^2$ is the most common mistake. If the second difference is negative, the $n^2$ term is negative too.
